# SEO launch checklist

## Already built into the structure

- Server-rendered, pre-generated HTML for fast crawling and page speed.
- One descriptive, permanent URL and one search intent per calculator.
- Unique title, meta description, H1 and canonical URL per page.
- Indexable explanatory copy and FAQs outside the interactive result.
- WebApplication, FAQPage and BreadcrumbList JSON-LD.
- Internal links between the calculator hub and all tools.
- A calculator-only XML sitemap that can be submitted alongside the WordPress sitemap.
- Responsive, semantic, accessible controls with no login required.

## Content work required before launch

- Replace placeholder rates with estimator-approved UAE data and state “last reviewed” month/year.
- Explain exactly what every estimate includes and excludes.
- Add real project examples, original photos, author/reviewer names and engineering credentials.
- Create Arabic equivalents with separate URLs and `hreflang` only after complete human-reviewed translation.
- Add the tools to the WordPress header/footer and link relevant service/blog content to them.
- Add a useful lead form only with consent text and a published privacy policy; avoid blocking the result behind a form.

## Technical launch checks

- Force one HTTPS hostname and redirect all HTTP/non-canonical variants.
- Confirm `/tools/` returns 200, not a soft 404, and is not blocked by WordPress or security plugins.
- Validate structured data with Google's Rich Results Test.
- Inspect rendered HTML and canonicals in Google Search Console.
- Submit the WordPress and calculator sitemaps.
- Test Core Web Vitals on mobile and optimize local images to WebP/AVIF.
- Connect Google Search Console and privacy-conscious analytics; track calculation completion and qualified contact clicks.

SEO is earned through accurate, original, useful content and reputable local signals. Metadata and schema improve understanding, but cannot guarantee rankings.
